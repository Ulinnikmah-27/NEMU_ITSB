# NEMU_ITSB
NEMU (Navigasi Eksplorasi Minat UKM) adalah aplikasi web berbasis Python dan Streamlit yang membantu mahasiswa ITSB menemukan UKM sesuai minat, kemampuan, dan preferensi kegiatan. Dilengkapi fitur rekomendasi, pendaftaran UKM, pengelolaan seleksi, serta grafik dan analisis untuk mahasiswa, pengurus UKM, dan admin.
